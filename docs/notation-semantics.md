## 0. 通用约定

- `{L}`：扩展超运算的序数层（README extended arrow rules (i)–(v)）。`x{L}y` 表示以 `x` 为底、层 `L`、参数 `y`。有限 `L` 即 Knuth 箭头族。
- `int(α)` / `frac(α)`：实数 α 的整数 / 小数部分。`⌊α⌋ = int(α)`。
- `ω`：首个超限序数。`ω^0=1`。
- 对角字母：以 `a` 结尾的字母组合（`Aa`、`Ba`、`Aaa`、…）携带连续参数；其“光滑”参数曲线为 `α = 2·5^f`（`f∈[0,1)`）。
- 符号层：`!`（ω^ω 层）、`@`（ω^ω^ω）、`#`、`$`、… 每个符号在层上再加一个 `ω^`。
- 库内部用 `layer` 字段 + 序数行 `[count, c…, diag]` 表示 `ω^ω` 及以上（见 `issues.md` 的表示约定）。

## 1. 决策 1（B）· `!Aaα`（α 为实数）

**定义**

```
!Aaα  ≡  A(a×⌊α⌋)(α)          （α ≥ 1，非整数）
```

即：取字母 token `A` + `⌊α⌋` 个小写 `a`，以 `α` 为参数求值。等价地，基数行为 `[α]`、序数行为 `[1, 0×⌊α⌋, 1]`。

- α 为整数 `n` 时（issue #19 修订）：`!Aan = 10{ω^n}10`——"!" 给层号加一个 `ω^`，
  存为完整 rule-3 级联（base `[10]` + maxRows−1 行序数行，顶行 `[8, 9×n]`，layer 0），
  高阶符号同一 array 逐层 +1：`@Aa3`（layer 1）= 10{ω^(ω^3)}10，`#Aa3`（layer 2）。
  故 `!Aa1 = 10{ω}10 = 10{10}10 = Aa10`（README 原始锚点恢复成立），而
  `!Aa2 = 10{ω^2}10 ≠ Aaa2`（token 应用与对角级联是两回事）。
  超出预算时（n ≥ maxCols）层数 +1，其余按去掉 ! 的方式处理：`[[n],[1,0,1]]`。
- α∈[0,1) 时 `⌊α⌋=0`，取 `max(1,⌊α⌋)=1`，即 `!Aaα = Aaα`（第一对角元的连续延拓）。
- α 非整数时保持本决策的连续延拓（`!Aa1.5 = Aa1.5`、`!Aa2.5 = Aaa2.5`），其紧凑形
  `[[x],[1,0×k,1]]` 的 format 拼写为裸形式 `Aa x`（x<2）/ `!Aa x`（x≥2），按显示有效位
  近似往返（容差；issue #20：旧的二进制 `!αAaβ` 尾数反推有浮点误差，且 x∈[1,2)
  被 carrier 到 `αΓβ` 时 parser 会丢失整个值）。

**为什么不是 README 字面式**

README 写 `!Aaα = 10{ω^int(α)·frac(α)}10`。按普通乘法在整数处会得 `ω^n·0 = 0`（例如 `!Aa1 = 10{0}10 = 100`），与紧邻的 `!Aa1 = Aa10` 自相矛盾。该式应理解为 rule (v) 的「数字分配」简写，不能作为可执行定义。决策 1 采用 (B)：保留库中经测试的整数锚点，`frac` 只做区间内连续延拓。

**锚点对照**

| α | `!Aaα`（本文/实现） | 备注 |
|---|---|---|
| 0.5 / 1.5 / 2.5 / 3.5 | `Aaα` / `Aaaα` / …（连续延拓） | 非整数 |
| 1 | `10{ω}10 = 10{10}10 = Aa10` | 整数对角 |
| 2 | `10{ω^2}10`（19 行级联） | 整数对角 |
| 3 | `10{ω^3}10`（19 行级联） | issue #19 |
| n | `10{ω^n}10` | 整数对角 |

**验收向量**（`test_mixed.js`）：`!Aa0.5/1.5/2.5/3.5` 非零且紧凑族单调；`!Aa1.5=Aa1.5`、`!Aa2.5=Aaa2.5`；`!Aa1=Aa10`、`!Aa2=10{ω^2}10`、`!Aa5=10{ω^5}10`；`Aa3=2Aa3=[[10^10,8,8]]`；`!Aa3` 为 20 行级联且 layer=0，`@Aa3`/`#Aa3` 同 array 于 layer 1/2。

## 2. 决策 2 · `!αAaβ`（二元式）

**定义（数学）**

```
!αAaβ  =  !Aa( β + log₅(α/2) )          （α ∈ [2,10)，β ≥ 0）
```

`log₅(α/2)` 是 README `α = 2·5^f` 的逆：α=2 时该项为 0，故 `!2.0000Aa4 = !Aa4`，与 README 的 `10{ω⁴}10` 锚点一致（此前被误读为 `log₁₀`）。

**实现（A1，已落地）**

解析器把 `!αAaβ` 按上式映射到真实值 `!Aa x`（x = β+log₅(α/2)）：

- 当零行长度 `⌊x⌋+2 ≤ maxCols`（x≥2）时，存为去层实例 `[[x],[1,0×⌊x⌋,1]]`（layer 0）；
- 当 `⌊x⌋` 太大或 x≥19 时，存为 layer-1 marker `[[x],[1,0,1]]`；
- x<1 时 `!Aa x = Aa x`。

formatter 新增 `formatBangAaValue`：识别去层形状 `[[x],[1,0×k,1]]`（k=⌊x⌋, x≥2）并输出
`!α'Aa'β'`（β'=⌊x⌋, α'=2·5^(x−β')），与 parser 严格往返。

**保留项**：`α = 1.000`（带小数点的 legacy 写法）仍按“无 mantissa”处理（`!1.000Aa5 = !Aa5`），仅 α=1 且无小数时走公式。

**验收向量**（`test_mixed.js`）：`!2.5Aa4 == !Aa(4+log₅(2.5/2))`；`!1.5Aa4`/`!1Aa1.5` 非 0；`!2.0000Aa4 == !Aa4`；`format(!2.5Aa4) == "!2.500Aa4"` 且往返；`!2.376Aa999` 往返；`!1.000Aa5 == !Aa5` 不回归；`@Aa1`/`#Aa1` 经 `!1.000N10`/`@1.000N10` 精确往返；`Aa1.05..Aa1.95` 全部在 slog 容差内往返；`@Aa1.5`/`@Aa2.5`/`#Aa2.5` 经 `!Aaa1.5`/`!Aaaa2.5`/`@Aaaa2.5` 精确往返。

**已知残余**（精度/边界）：
- `!1Aa1.5`、`!Aa2.5` 等 x<2 或 mantissa 位数不足的值，`format` 往返在浮点精度下不严格相等（需容差）；
- 非整数单对角标记（`@Aa1.5` 等）已改为精确 token 形（`!Aaa1.5`）并严格往返；超过 `multiLetterLimit` 的标记（如 `Aaaaa3.5` → `!1.000H10`）仍走进位近似；
- α≥2 时 `!Aan` 的显示已校正为 anchor-B（`!Aa3` → `!2.000Aa3`，旧为 `2.000Aaaa10`）。

## 3. 决策 3 · 基数列 `λ[b]`（rule 3）

`x{λ}y = x{λ[y]}x` 中的 `λ[y]` 本次仅需定义到 `ω^(ω^ω)`。

**Cantor 正规形（有限 coeffs）：** 写 `λ = ω^p·c_p + ω^(p-1)·c_{p-1} + … + c_0`（`p` 为最小使 `c_p>0` 的指数 ≥1），则

```
λ[b] = ω^p·(c_p − 1) + ω^(p-1)·b + (低阶项)
```

（与 `fsCoeffs` 一致；`b` 可为小数，系数按 rule (v) 分配。）

**层状（`layer`/marker）λ 的基数列**（与各专用方法注释一致）：

| λ | λ[b] |
|---|---|
| `ω^ω` | `ω^b` |
| `ω^ω·2` | `ω^ω + ω^b` |
| `ω^(ω+1)` | `ω^ω·b` |
| `ω^(ω·2)` | `ω^(ω+b)` |
| `ω^(ω²)` | `ω^(ω·b)` |
| `ω^(ω^ω)` | `ω^(ω^b)` |
| ε 层 | 同类逐层对角化 |

**推论（D07 判定依据）**

反复应用 rule 3 且保持参数为 `n`，`n{λ}2` 最终坍缩到 `n{2}n`。当 `n=2` 时恒为 `2{2}2 = 2² = 4`。

> **注意**：对 `n≥3` **不存在** `n{λ}2 = n²`。例：`3{ω}2 = 3{2}3 = 3↑↑3`（巨大）。`issue-17-defects.md` D07 曾把“x=3,4,5 时 =x²”列为验收，**该条与 rule 3 矛盾，已作废**。

**B2-a（已实现）**：由 rule 3，对任意极限/后继层 `λ` 与整数 `y≥2`，`2{λ}y` 会把参数退回 2 并坍缩，故恒等于 `2{2}2 = 4`（有限层不适用：`2{1}3=8`、`2{2}3=16`）。已在 `_hyperopFromOrdinal`/`_ordinalHyperop`（含 `ω` 项时）与 8 个 marker 方法中落为快速路径。

**x≥3 的限制**：`3{ω^ω·2}2 = 3{ω^ω+ω²}3` 的精确级联是天文数字，超出任何可表示范围；库只能用 marker 近似（`layer`+行，base 10）。这不是 bug，而是表示能力的固有上界。B2-b..d 若要继续，需先引入中间序数的正规形与预算截断；当前标记为**近似**（见 `d07-engine-design.md` §6）。

## 4. 决策 4 · `toBeaf()` 可表示范围与不可表示行为

**可表示（返回 BEAF 文本）**

| 内部形式 | 输出 | 往返 |
|---|---|---|
| `layer=0`，单行，`r0` 长度 1 | `{r0[0]}` | — |
| `layer=0`，`r0=[e,1]`，`sign=1`，`e≥1` | `{10, e}` | `fromBeaf` 一致 |
| 次单位（`sign=2` / `sign=-2`） | `{…}⁻¹` / `-{…}⁻¹` | `fromBeaf` 一致 |
| 负值（`sign=-1`） | `-{…}` | `fromBeaf` 一致 |
| 其它 `layer=0` 单行（巨大有限值） | `{r0[0]}`（历史近似，README 记录） | — |

**不可表示**：多行（序数行）/ `layer>0` 的值**抛出** `MetaNumUnrepresentableError`（`code = METANUM_UNREPRESENTABLE`）。不输出内部 `[...]`，不使用占位 `?`。

次单位与负值是**明确降级**（不是静默丢失）：符号与底数都写进输出，且 `fromBeaf` 能还原；
回归向量见 `test_mixed.js` 的 D02 段（`1e-320 → {10,320}⁻¹`、`-5 → -{5}` 等）。

理由：序数行无法反推 BEAF 的迭代次数 `b`，静默降级会掩盖信息丢失。

## 5. 决策 5 · 小数量级 `pow`

- `pow(10, α)` 对有限 α 必须满足 `α<0 ⟺ 值<1`；次正规数（≈5e−324）以下允许精度损失，**不允许符号翻转**。
- 内部：`10^e` 快路径仅对正指数生效；负指数走 `log`/规格化路径，得到次单位编码（`sign=2`，`r0` 存倒数）。`log10` 对次单位 E 形式返回负指数，故 `10^-324 · 10^324 = 1`。

**验收向量**：`pow(10,α).lt(1)`（α=−320…−400 且单调）；`pow(10,-324).mul(1e324).eq(1)`；`log10(10^-324)=-324`。

## 6. README 已知矛盾与勘误（2026-10-16 已全部更正）

1. `!Aaα = 10{ω^int(α)·frac(α)}10` —— 整数处退化为 `10{0}10=100`，与 `!Aa1=Aa10` 矛盾。以 §1 的 (B) 定义为准；整数字符现已实现为 `10{ω^n}10` 对角级联（issue #19）。
2. `!Aa1 = Aa10, !Aa2 = Aaa10, …` —— `!Aa1 = Aa10` 现已成立（两者都是 `10{10}10`）；`!Aa2 = Aaa10` 不成立（`!Aa2 = 10{ω^2}10`，`Aaa10` 是紧凑 ω² 标记），README 已按 §1 改写。
3. `!αAaβ = !Aa(β+log α)` —— 其中的 `log` 是 `log₅(α/2)`，否则 `!2.0000Aa4` 不成立；README 已改。
4. `!2.0000Aa4 = 10{ω⁴}10` 与 `Aaα = 10{α}10` 的层号约定存在 off-by-one 的表述差异 —— 按修订后语义 `!2.0000Aa4 = !Aa4 = 10{ω^4}10` 精确成立（α=2 时 `log₅(2/2)=0`），README 已注明。
